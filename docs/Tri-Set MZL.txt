🔶 Ebene I – STRUCTURAL TOPOLOGY (MZL_Topology_V2.svg)

Funktion:
Visualisiert das Netzwerk-Skelett des Korpus.

Achsen: Resonanz (horizontal) × Komplexität (vertikal)

Zentrale Knoten: PRIMAFORM → ECHOFORM → PATHFORM → ROOTFORM → FORMGESELLSCHAFT → VERNUNFTKÖRPER

Querachsen markieren Brückenfelder (z. B. Myth ↔ Ethik ↔ System)

Ausgabeziel:
Das SVG bleibt der Grundriss des semantischen Organismus.

🧩 Synthese („Tri-Set Mapping“)
[ TOPOLOGY ]   ← räumliche Ordnung
      │
      ▼
[ BRIDGEFORM KITS ]   ← Bewegungsachsen
      │
      ▼
[ FORMGESELLSCHAFT / SYSTEMSEED / VERNUNFTKÖRPER ]   ← institutionalisierte Wirkung


Daraus ergibt sich:

Topology = Struktur
Bridgeform = Übergang
Constitution = Selbstorganisation

Das Tri-Set beschreibt also den myzelischen Übergang von Form → Struktur → System, den Punkt, an dem das MZL vom poetischen Organismus zur politischen Grammatik wird.
